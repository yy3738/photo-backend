## 1. 项目概述

### 1.1 背景

摄影师群体普遍面临作品变现渠道单一、版权保护薄弱的问题。买家在寻找高质量授权图片时，流程繁琐、沟通成本高。本项目通过微信小程序搭建轻量化的摄影作品交易与授权平台，降低双方交易门槛。

### 1.2 产品目标

- 为摄影师提供作品展示、版权保护、在线积分收益的完整闭环
- 为买家提供合规授权图片的便捷购买渠道
- 平台通过积分体系实现内部流通，后续迭代支持充值与提现

### 1.3 产品范围

**本期（MVP）包含：**
- 摄影师端：注册即可上传 / 管理作品 / 查看积分收益
- 买家端：浏览 / 搜索 / 积分购买 / 授权申请
- 管理员端：审核 / 收录 / 用户管理 / 分类标签管理（小程序内嵌管理页）

**本期不包含：**
- 积分充值与提现（后续迭代）
- 摄影师等级 / 勋章体系
- 图片 AI 自动打标
- 批量授权 / 企业账户
- 独立 Web 管理后台

### 2.3 RBAC 权限模型

为支持灵活的权限管理，系统引入 RBAC（基于角色的访问控制）模型，包含组织、角色、菜单三个维度：

**组织管理**
- 支持树形组织/部门结构（parent_id 自关联）
- 每个用户归属一个组织（t_sys_user.org_id）
- 组织可启用/禁用

**角色管理**
- 角色通过 code 唯一标识（如 `buyer`、`photographer`、`admin`）
- 用户与角色为多对多关系（通过 t_sys_user_role 关联）
- 保留 `t_sys_user.role` 字段做业务快捷判断，RBAC 权限通过关联表维护
- 角色可启用/禁用

**菜单与权限**
- 菜单采用三级结构：目录（dir）→ 菜单（menu）→ 按钮（button）
- 目录：一级导航分组
- 菜单：具体页面路由
- 按钮：页面内操作权限（如 `photo:review`、`user:ban`）
- 角色与菜单为多对多关系（通过 t_sys_role_menu 关联）
- 分配角色时勾选对应菜单/按钮，即完成权限配置

## 3. 积分规则

| 规则 | 说明 |
|------|------|
| 兑换比例 | 1元 = 10积分 |
| 消耗 | 买家购买作品时按作品积分价格扣除 |
| 获得 | 摄影师作品被购买后获得对应积分（平台抽佣 10%，摄影师实得 90%） |
| 查看 | 个人中心可查看积分余额和明细 |
| 充值 | 本期不做，后续迭代 |
| 提现 | 本期不做，后续迭代 |

## 4. 分类与标签体系

采用两层结构：**分类（Category）→ 标签（Tag）**

- 分类：粗粒度，如「风景」「人文」「商业」「动物」等，由管理员维护
- 标签：细粒度，归属于某个分类，如「风景」下有「山川」「海洋」「城市」等
- 摄影师上传作品时：选择一个分类 + 最多 5 个标签
- 首页：分类 Tab 切换 + 对应作品瀑布流
- 搜索：支持按分类、标签、关键词筛选

## 5. 功能模块清单

### 5.1 通用模块

**登录与身份**
- 微信一键授权登录（获取 openid）
- 登录后自动同步微信昵称和头像
- 未登录访问受限功能时弹出登录引导弹窗
- 登录态持久化，token 过期自动刷新（access token 有效期 2h，refresh token 有效期 7d）

**消息通知**
- 订阅消息：购买成功、授权审核结果、作品审核结果
- 站内消息中心：系统通知列表，支持已读 / 未读状态

---

### 5.2 买家模块

**作品浏览**
- 首页：顶部分类 Tab + 下方瀑布流（按时间倒序）
- 分类 Tab：全部 + 各分类，点击切换对应作品列表
- 标签筛选：在分类内可进一步按标签筛选
- 关键词搜索：按作品标题、标签搜索
- 作品详情：水印预览图、标题、摄影师信息、积分价格、分类、标签

**购买流程**
- 详情页点击「积分购买」→ 积分确认弹窗（展示当前积分余额和所需积分）
- 积分不足时提示余额不足（本期不做充值引导）
- 购买成功后解锁原图下载权限，触发订阅消息通知
- 已购买作品在详情页显示「下载原图」按钮

**授权申请**
- 入口：作品详情页「申请授权」按钮（与购买独立，无需先购买）
- 填写表单：使用用途（下拉：商业广告 / 新闻媒体 / 个人创作 / 教育出版 / 其他）、使用场景描述（200字内）、使用期限（自由填写，文字描述）、联系方式（手机号）
- 提交后可在「我的授权」查看进度

**个人中心（买家）**
- 积分余额展示
- 我的订单：已购买作品列表，支持再次下载
- 我的授权：申请列表及状态（待审核 / 已通过 / 已拒绝）
- 开启摄影师模式入口

---

### 5.3 摄影师模块

**开启摄影师模式**
- 个人中心点击「开启摄影师模式」，无需审核，立即生效
- 开启后个人中心新增「我的作品」「积分收益」入口

**作品上传**
- 选择本地图片，单次最多 9 张
- 客户端压缩后 OSS 直传（预览图压缩至 800px 宽、质量 80%；原图不限大小；后端提供签名 URL）
- 填写信息：
  - 标题（必填，50字内）
  - 描述（选填，500字内）
  - 分类（必填，单选）
  - 标签（必填，从所选分类下选择，最多 5 个）
  - 积分定价（必填，单位：积分，范围：10 ~ 9999 积分）
  - 是否允许授权申请（开关，默认开启）
- 提交后状态为「待审核」

**作品管理**
- 作品列表：展示全部作品及状态（待审核 / 已上架 / 已下架 / 审核拒绝）
- 已上架可手动下架；已下架可重新上架
- 审核拒绝可查看原因，修改后重新提交
- 编辑：可修改标题 / 描述 / 分类 / 标签 / 积分定价（可修改定价，仅影响后续购买）
- 删除：有购买记录的作品不可删除，仅可下架

**积分收益**
- 收益概览：总积分收益、本月积分收益、当前积分余额
- 收益明细：每笔收入（作品名、积分数、时间）

**授权确认**
- 管理员审核通过的授权申请推送给摄影师确认
- 查看申请详情（用途、场景、期限、联系方式）
- 操作：同意 / 拒绝（拒绝需填写原因）
- 同意后系统生成授权证书 ⚠️ 待确认：证书格式（PDF/图片）与内容字段

---

### 5.4 管理员模块

**作品审核**
- 待审核队列（按提交时间排序）
- 审核详情：查看原图（无水印）、作品信息、摄影师信息
- 通过：作品上架，通知摄影师
- 拒绝：填写原因（预设：画质不达标 / 内容违规 / 信息不完整 / 重复上传 / 其他），通知摄影师

**授权申请审核**
- 待审核列表，查看申请信息 + 作品信息 + 申请人信息
- 通过：转交摄影师确认；拒绝：填写原因，通知买家

**用户管理**
- 用户列表，支持搜索（昵称 / 手机号）
- 操作：封禁 / 解封账号

**分类与标签管理**
- 分类管理：新增 / 编辑 / 删除分类，设置排序
- 标签管理：新增 / 编辑 / 删除标签，归属分类，设置排序
- 删除分类前需确认该分类下无作品

**数据概览**
- 今日 / 本月：新增用户、新增作品、积分交易量、交易笔数
- 待处理事项：待审核作品数、待审核授权申请数（快捷入口）

## 6. 核心业务流程

### 6.1 作品上架流程

```
摄影师选择图片
  → 客户端压缩（预览图压缩至 800px 宽、质量 80%；原图不限大小）
  → 获取 OSS 上传签名（调后端接口）
  → 原图 + 预览图直传 OSS
  → 填写作品信息（标题 / 分类 / 标签 / 积分定价等）
  → 提交，后端创建作品记录（状态：待审核）
  → 管理员审核：
      [通过] → 状态变为「已上架」，水印预览图对外可见
               → 订阅消息通知摄影师
      [拒绝] → 状态变为「审核拒绝」，记录拒绝原因
               → 订阅消息通知摄影师
  → 摄影师可查看原因，修改后重新提交
```

### 6.2 积分购买流程

```
买家浏览作品（水印预览图）
  → 点击「积分购买」
  → 未登录：弹出登录引导 → 微信授权登录 → 返回详情页
  → 已登录：展示积分确认弹窗（所需积分 / 当前余额）
  → 积分不足：提示余额不足
  → 积分充足：确认购买
      → 后端原子扣减买家积分 + 增加摄影师积分（扣除平台抽佣）
      → 生成购买记录
      → 订阅消息通知买家
  → 买家点击「下载原图」
      → 后端验证购买记录 → 返回 OSS 原图临时签名 URL（5分钟有效）
      → 前端调用微信 API 保存图片到相册
```

### 6.3 授权申请流程

```
买家点击「申请授权」
  → 填写授权申请表单
  → 提交 → 后端创建申请记录（状态：待管理员审核）
  → 管理员审核：
      [拒绝] → 状态变为「已拒绝」，通知买家 + 原因
      [通过] → 状态变为「待摄影师确认」，通知摄影师
  → 摄影师确认：
      [拒绝] → 状态变为「已拒绝」，通知买家 + 原因
      [同意] → 状态变为「已授权」
               → 系统生成授权证书
               → 通知买家，可下载授权证书
```

## 8. 非功能性需求

### 8.1 性能

| 指标 | 要求 |
|------|------|
| 首屏加载 | 3秒内可见（4G 网络） |
| 图片加载 | 列表页使用 OSS 缩略图（800px 宽），不加载原图 |
| 上传 | OSS 直传，前端展示上传进度条 |
| 接口响应 | 普通查询 P99 < 500ms |
| 分页 | 列表上拉加载更多，每页 20 条 |

### 8.2 安全

**图片保护**
- 预览图服务端使用 OSS 图片处理规则自动添加文字水印（平台名称 + 作品ID），覆盖核心区域
- 原图 OSS 存储桶设为私有，通过后端签名 URL 访问，有效期 5 分钟
- 禁止前端直接暴露原图 OSS 路径

**积分安全**
- 积分扣减和增加必须原子操作，防止并发超扣
- 积分变更全程记录流水，不可篡改

**接口安全**
- 所有需登录接口验证 JWT token
- 管理员接口额外验证角色权限
- 上传接口限流：每用户每分钟 10 次

### 8.3 兼容性

| 维度 | 要求 |
|------|------|
| 微信版本 | 8.0 及以上 |
| 小程序基础库 | 2.20.0 及以上 |
| 机型 | iOS 13+ / Android 8+ |
| 屏幕宽度 | 320px - 428px，统一使用 rpx |
| 弱网 | 3G 环境下给出友好提示，不崩溃 |

### 8.4 体验

- 所有异步操作有明确 loading 状态，防止重复点击
- 网络/服务器错误给出具体提示，不显示「系统错误」
- 关键操作（删除作品）需二次确认弹窗
